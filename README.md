# Stakeholder Matrix — Portfolio Demo

Interactive demo of a stakeholder interest-power matrix built with React, TypeScript and clean architecture.

> **Disclaimer:** Portfolio demo inspired by professional work. All data is fictional. Not affiliated with any employer, client, or government entity. Source was rewritten for public display; internal repos are not published.

## Features (demo)

- Interest-power matrix dashboard
- Actor CRUD with filters
- Catalogs (orgs, categories, roles, districts, municipalities)
- Auth UI with mocked session (MSW)
- Fake seed data only — no real backend
